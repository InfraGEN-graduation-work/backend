# Roadmap 인덱스

`docs/roadmap/`에는 현재 상태를 기록하는 v1과, 앞으로의 마일스톤을 담는 v2를 둔다.
각 문서는 제목에 버전을 포함하고, 이 인덱스가 첫 진입점이다.

## 읽는 순서

1. [backend-roadmap-v2.md](./backend-roadmap-v2.md)로 지금부터의 우선순위를 확인한다.
2. [backend-roadmap-v1.md](./backend-roadmap-v1.md)로 현재 상태와 진행 이력을 확인한다.
3. [backend-implementation-plan.md](../plan/backend-implementation-plan.md)로 상세 실행을 확인한다.

## 문서 역할

- `backend-roadmap-v2.md`: 활성 로드맵 v2, 앞으로 남은 마일스톤
- `backend-roadmap-v1.md`: v1 아카이브 성격의 현재 상태 기록
- `backend-implementation-plan.md`: 세부 실행 계획
