# Plan 인덱스

`docs/plan/`에는 상세 실행 계획과 작업 단위 계획을 둔다.

## 문서 목록

- [backend-implementation-plan.md](./backend-implementation-plan.md): 통합된 단일 실행 계획. Generate, B-TF, Redis, 문서 정합화까지 포함
- [backend-generation-execution-plan.md](./backend-generation-execution-plan.md): 과거 경로 호환용 포인터. 본문은 `backend-implementation-plan.md`

## 읽는 순서

1. 먼저 `backend-implementation-plan.md`로 전체 실행 계획을 확인한다.
2. 세부 상태는 `docs/roadmap/`의 로드맵 문서를 확인한다.
3. `backend-generation-execution-plan.md`는 옛 링크 호환이 필요할 때만 참고한다.
